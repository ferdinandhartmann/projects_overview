# Robotics Projects

Static GitHub Pages portfolio for selected robotics and AI projects by Ferdinand Hartmann.

Open `index.html` directly or serve the folder with any static file server.

## Run locally

From this folder:

```bash
python3 -m http.server 8001
```

Then open `http://localhost:8001` in a browser.

You can also open `index.html` directly in a browser because the site has no build step or runtime dependencies.
